About this development build

Shields controls domain-rule filtering on HTTP(S) sites. Check the toolbar for the current site policy and cumulative blocked count. This local home page does not display live browser metrics or verify privacy, sandbox, or GPU status. Website compatibility and security testing remain necessary.
